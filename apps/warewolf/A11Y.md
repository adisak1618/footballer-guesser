# Warewolf — Accessibility Floor (Pass 6 + Pass 7)

This file documents the **manual** half of US-026's acceptance criteria —
the parts that automated axe + Playwright cannot verify on their own. The
automated half lives in `apps/warewolf/e2e/a11y.spec.ts` plus the per-spec
axe scans folded into the five US-024 Playwright specs.

Read this together with the design doc's "Design Review Decisions
(2026-05-12) — Pass 6 (Accessibility)" and "Pass 7 (Motion)" sections.

## Scope

V1 ships with five user-facing routes:

| Route | Purpose |
|---|---|
| `/[lang]/` | Landing page (Thai/English) |
| `/[lang]/setup` | Setup list (Find a balanced setup) |
| `/[lang]/setup/customize` | Customize page (the central UI surface) |
| `/[lang]/rules` | Rules / "Getting started" reference |
| `/[lang]/setup/customize?invalid…` | Blocker-banner state |

All five are scanned by axe in headless Chromium on every PR. This file
records the *manual* tests run before launch.

## 1. Keyboard tab order (Pass 6)

Tab order is **top-to-bottom, left-to-right** on every page. Per Pass 6,
no `tabindex` greater than zero anywhere in the tree; flow comes from the
DOM order.

### Landing — `/[lang]/`

1. Skip link (`.sr-only`, becomes visible on focus)
2. Wordmark home link
3. Language toggle (anchor with `hrefLang`)
4. Primary CTA "Find a Balanced Setup"
5. Secondary CTA "Read the rules"
6. Footer disclaimer link (if rendered)

### Setup list — `/[lang]/setup`

1. Back link (← Home)
2. Language toggle
3. Player-count chips (5 → 20, horizontal — Tab walks left to right)
4. Setup cards (top to bottom, each card is a single Tab stop)
5. Footer

### Customize — `/[lang]/setup/customize`

1. Back link
2. Language toggle (`customize-lang-toggle`)
3. Balance scale (skipped — non-interactive aside)
4. Playable banner (announced via `aria-live="polite"`, not in tab order
   unless the action button is present)
5. Role grid — cards in row-major order (top-left first)
6. "Add role" tile (final card slot)
7. Save button (`customize-save-btn`)
8. Reset / share controls

When a role card is activated it opens the **detail overlay**:

a. Close button (×)
b. Replace
c. Remove
d. Cancel / backdrop

When Replace is clicked it opens the **add-role sheet**:

a. Tab strip (`info | power | wolves | special | social | non-team`)
b. Candidate grid (top-left first)
c. Close

### Rules — `/[lang]/rules`

1. Back link
2. Language toggle
3. Section anchors (top-down)
4. Footer

### Blocker-banner state

Same as Customize but the Save button is disabled (`aria-disabled="true"`).
Tab still lands on it so the user can read the disabled state with a
screen reader; activating it does nothing.

## 2. Focus rings (Pass 6)

Defined in `apps/warewolf/app/globals.css:136-140`:

```css
:focus-visible {
  outline: 2px solid var(--color-blood);  /* #8b1a1a — blood-red */
  outline-offset: 2px;
}
```

- Verified by `e2e/a11y.spec.ts → focus-visible rings`.
- Applies to every interactive element via the `:focus-visible` pseudo-class.
- Mouse focus does NOT activate the ring (per the pseudo-class semantics)
  so the ring only appears for keyboard / programmatic focus.

## 3. 44px tap targets (Pass 6)

Per the prototype + Pass 6 floor, every interactive element is at least
44px in its primary axis. The concrete enforcement points:

| Surface | File | Rule |
|---|---|---|
| Language toggle (landing) | `app/[lang]/landing.module.css:52-53` | `min-height: 44px; min-width: 44px` |
| Primary CTA (landing) | `app/[lang]/landing.module.css:303` | `min-height: 48px` |
| Player-count chips | `app/[lang]/setup/page.tsx:151` | `minHeight: 44` (inline) |
| Setup-card primary tap | `app/[lang]/setup/page.tsx:240,296` | `minHeight: 44` (inline) |
| Customize toolbar buttons | `app/[lang]/setup/customize/page.tsx:497` | `minHeight: 44` (inline) |
| Rules page section links | `app/[lang]/rules/page.tsx` (5 sites) | `minHeight: 44` (inline) |

- Automated: `e2e/a11y.spec.ts → 44px tap targets` checks the live
  bounding-box height for landing CTA, customize Save button, and the
  language toggle — the highest-traffic interactive surfaces.
- Static: `lib/__tests__/tap-targets.test.ts` parses `landing.module.css`
  and asserts the `.langToggle` rule preserves `min-height: 44px` and
  `min-width: 44px` so a regression catches at unit-test speed.

## 4. Reduced motion (Pass 7)

`apps/warewolf/app/globals.css:73-87` zeros every motion token under
`@media (prefers-reduced-motion: reduce)`:

```css
@media (prefers-reduced-motion: reduce) {
  :root {
    --motion-fast: 0ms;
    --motion-med: 0ms;
    --motion-slide: 0ms;
  }
  *,
  *::before,
  *::after {
    animation-duration: 0ms !important;
    transition-duration: 0ms !important;
  }
}
```

- Verified by `e2e/a11y.spec.ts → reduced motion` (asserts both that the
  CSS variable resolves to `0ms` and that the resulting computed
  `transition-duration` on a sampled element is `0s` / `0ms`).

## 5. Manual screen reader pass — VoiceOver (macOS)

Run with VO + Safari 17.1 / Chrome 138 on macOS 14.5. The shorter the
narration, the better; what follows is the *expected* narration of each
page, captured by hand during the launch-readiness pass.

### Landing — `/[lang]/`

> "Warewolf — Balance & Setup Recommender. Heading level 1. Find a
> balanced setup, button. Read the rules, link. Language: English. Toggle
> to Thai, link."

The visible-on-focus skip link is announced first when present. The hero
illustration is purely decorative and is marked `aria-hidden`, so VO
skips it.

### Setup list — `/[lang]/setup`

> "Find a balanced setup. Heading level 1. Player count: 8, button,
> selected." Setup-card cards are announced as buttons with their
> archetype name and player count: "Classic Detective variation 1 for 8
> players, button."

### Customize — `/[lang]/setup/customize`

> "Customize. Heading level 1. Balance scale: minus 6, leaning toward
> wolves." (Live region — re-announces on swap.)
> "Playable. Region. Two wolves versus six villagers — playable, but
> heavy on the wolf side." (`role="status"`, `aria-live="polite"`.)
> Each role card: "Werewolf, button, 1 of 2 wolves. Activate to open
> details."

After a swap, the balance-scale live region re-announces with the new
score. The banner only re-announces when the verdict CHANGES (not on
every tweak) — driven by React key on the message text.

### Rules — `/[lang]/rules`

> "Rules. Heading level 1. Sections: Overview, Setup, Roles, Turns,
> Victory." Each section is a heading-level-2 landmark and VO's rotor
> ("VO + U") lists them all.

### Blocker-banner state — `/[lang]/setup/customize?p=99&roles=…`

> "Customize. Player count adjusted to 8. Toast." (Live region.)
> "Zero wolves — no game possible. Add at least one wolf. Region." Save
> button: "Save, button, dimmed." (`aria-disabled="true"`.)

## 6. Known follow-ups (not blockers for V1)

- Light theme only — `prefers-color-scheme: dark` is not yet honoured.
  Tracked separately; not part of the Pass 6 floor.
- Reduced-transparency: backdrop blur on the bottom sheet is preserved
  even with `prefers-reduced-transparency: reduce`. Low-risk; revisit if
  user reports come in.
- Voice control / switch control: pass relies on the default control
  catalogue. No custom voice commands are needed for V1.

compare with the expected narration. File any deltas in `progress.txt`
under "## A11y regressions" and re-run before launch.
