# US-017: `<RoleDetailModal>` + `<AddRoleSheet>`

**Lane:** E. Components
**Depends on:** US-008, US-013
**Priority:** 17

## Description
As a player editing my setup, I need a role detail modal that opens on tap (shows mechanic + Replace/Delete) and an add-role sheet (6 category tabs, multi-add) so I can edit my room composition without leaving the customize page.

## Acceptance Criteria

### `<RoleDetailModal>`
- [ ] `apps/warewolf/components/RoleDetailModal.tsx`.
- [ ] Props: `roleId: RoleId`, `slotIndex: number`, `onReplace: (slotIndex: number) => void`, `onDelete: (slotIndex: number) => void`, `onClose: () => void`.
- [ ] Layout per design doc lines 511–516:
  - Full card art via `<CardArt size="lg" roleId={...} />`.
  - Role name (en + th in current language).
  - Team / balance / category badges.
  - Mechanic description sourced from `apps/warewolf/source/game-rule/ultimate-roles.md` via `ROLES[roleId].i18n[lang].description`.
  - Two buttons: **Replace · เปลี่ยน** and **Delete · ลบ** (current language).
- [ ] **Replace** fires `onReplace` — caller opens `<AddRoleSheet>` with the same category tab pre-selected as the role being replaced (per Pass 7 — "Replace button filter").
- [ ] **Delete** fires `onDelete` — caller removes the role; modal closes.
- [ ] Mobile: bottom-sheet modal. Desktop (≥1024px): **sticky right-column panel** replaces the modal per Pass 6 ("Customize desktop layout ≥1024px"). Determine via CSS media query.
- [ ] **Escape** key closes the modal/panel per Pass 6.
- [ ] Slide-up animation 280ms `cubic-bezier(0.16, 1, 0.3, 1)`; respects `prefers-reduced-motion`.
- [ ] Focus traps inside modal; restores on close.

### `<AddRoleSheet>`
- [ ] `apps/warewolf/components/AddRoleSheet.tsx`.
- [ ] Props: `initialTab: TabKey`, `existingSetup: RoleId[]`, `onAdd: (roleId: RoleId) => void`, `onClose: () => void`.
- [ ] 6 tabs (`Wolves / Info / Power / Vanilla / Social / Neutral`) per `TABS` and `mapCategoryToTab` from US-008.
- [ ] `initialTab` pre-selected on open (used by Replace flow to pre-filter to the swapped role's tab).
- [ ] Per candidate card: shows role art, name, team/balance/category, and **balance delta** if added to current setup.
- [ ] Sheet **stays open for multi-add** — tapping a card calls `onAdd` and keeps the sheet open.
- [ ] Sheet is dismissed via X button or Escape per Pass 6.
- [ ] Slide-up animation 280ms; respects `prefers-reduced-motion`.

### Common
- [ ] Tests written: `apps/warewolf/components/{RoleDetailModal,AddRoleSheet}.test.tsx`:
  - Modal: renders mechanic + buttons; Replace fires callback; Delete fires callback; Escape closes.
  - Sheet: 6 tabs render; switching tabs filters roles; tap-add fires callback; sheet stays open after add.
- [ ] Typecheck passes: `cd apps/warewolf && bunx tsc --noEmit`.
- [ ] Lint passes: `bun run lint`.
- [ ] Verify in browser using dev-browser skill (mobile + desktop viewports).

## Technical Notes
- Per Eng Review decision #6: tab filtering uses `mapCategoryToTab(role)` from US-008 — no new fields on Role.
- Desktop 2-column layout is locked at Pass 6; on `≥1024px`, render the sheet as a sticky right column instead.
- Replace pre-filters per Pass 7 resolved decision ("Replace Seer → Info tab active").
