# US-013: `<CardArt>` + `<CardArtPlaceholder>`

**Lane:** E. Components
**Depends on:** US-009, US-012
**Priority:** 13

## Description
As a developer, I need a card-art component that loads role images via `next/image` and falls back to a Grimoire-styled placeholder on 404 so a missing image never shows a broken-image icon.

## Acceptance Criteria
- [ ] `apps/warewolf/components/CardArt.tsx` exports `<CardArt>` (Client Component if needed for the error fallback).
- [ ] Props: `roleId: RoleId`, `size?: 'sm' | 'md' | 'lg'`, `priority?: boolean` (for above-the-fold cards).
- [ ] Renders `next/image` pointing at `cardArtPath(roleId)` from US-012.
- [ ] On error (404 or load failure), renders `<CardArtPlaceholder roleId>` — a Grimoire-styled empty card: parchment background, blood-red wax-seal silhouette, role name in Cormorant, role's balance value as a corner badge.
- [ ] Sizes (small = setup-card thumbnail, medium = customize grid, large = role detail modal) match prototype CSS.
- [ ] Honors `next/image` priority prop for above-the-fold rendering (used by US-019 landing card-fan).
- [ ] Tests written: `apps/warewolf/components/CardArt.test.tsx`:
  - Renders `<img>` with src pointing at the WebP path.
  - On simulated 404 (mock the load handler), renders the placeholder.
  - Placeholder shows the role name.
- [ ] Typecheck passes: `cd apps/warewolf && bunx tsc --noEmit`.
- [ ] Lint passes: `bun run lint`.
- [ ] Verify in browser using dev-browser skill (Storybook-style render of all 22 cards).

## Technical Notes
- Per Eng Review failure-mode mitigation #2: card image 404s need a real fallback, not the broken-image default.
- Placeholder is a real component because it ships visual identity; don't fall through to `alt` text alone.
- Component is reused by US-016 (SetupCard), US-017 (RoleDetailModal), US-019 (landing fan), US-021 (customize grid).
