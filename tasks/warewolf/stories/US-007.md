# US-007: Share URL — `apps/warewolf/lib/share-url.ts`

**Lane:** A. Data
**Depends on:** US-001
**Priority:** 7

## Description
As a developer, I need encode/decode helpers for the share-URL format so any setup can round-trip through the URL as the single source of truth for shareable state.

## Acceptance Criteria
- [ ] File created at `apps/warewolf/lib/share-url.ts`.
- [ ] Defines `ShareUrlSchema` (Zod) matching this exact shape:
  ```ts
  z.object({
    p: z.coerce.number().int().min(5).max(20).catch(8),
    roles: z.string()
      .transform(csv => csv.split(','))
      .pipe(z.array(z.string()))
      .transform(ids => ids.map(id => ROLES[id] ? id : 'villager')),
    lang: z.enum(['en', 'th']).default('en'),
  })
  ```
  Per design doc Eng Review section "Share URL Zod schema (now explicit, was implied)".
- [ ] Exports `encodeSetup({ playerCount, roles, lang }): URLSearchParams`.
- [ ] Exports `decodeSetup(searchParams: URLSearchParams | string): { playerCount: number; roles: RoleId[]; lang: 'en' | 'th'; clampedP: boolean; substitutedIds: string[] }`.
  - `clampedP` is `true` when the URL `p` was out-of-range (used by UI to show a toast).
  - `substitutedIds` lists unknown role IDs that were silently replaced with `villager` per Eng Review decision #3.
- [ ] **Parser is the SINGLE source of unknown-id handling**: unknown role IDs become `villager` silently. The validator never sees unknowns in production. Per Eng Review decision #3.
- [ ] `decodeSetup` defaults: missing `p` → 8, missing `roles` → `['villager']`, missing `lang` → `'en'`.
- [ ] Tests written: `apps/warewolf/lib/share-url.test.ts`:
  - **Round-trip:** `decodeSetup(encodeSetup(x)).{playerCount,roles,lang}` === `x` for any valid input.
  - `p` out-of-range clamps to [5, 20], `clampedP` is `true`.
  - Unknown role id → `villager`, `substitutedIds` includes the original.
  - `roles=foo,bar` → `['villager','villager']`, `substitutedIds === ['foo','bar']`.
  - URL length stays < 2048 chars at 20 players (any role mix).
  - Missing params → defaults.
- [ ] Typecheck passes: `cd apps/warewolf && bunx tsc --noEmit`.
- [ ] Lint passes: `bun run lint`.

## Technical Notes
- Per Eng Review decision #3: this is the sole substitution point. Defense-in-depth would hide bugs.
- Per Eng Review decision #5: locale precedence is handled at the route/middleware layer (US-011), not here. `lang` in `decodeSetup` is only the query value; the segment is canonical.
