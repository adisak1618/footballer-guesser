# US-024: E2E specs (5) + clipboard fallback + card 404

**Lane:** G. Tests + perf
**Depends on:** US-019, US-020, US-021, US-022
**Priority:** 24

## Description
As a maintainer, I need Playwright E2E specs covering the 5 critical user flows plus the two critical failure-mode tests (clipboard fallback, card 404), so the customer-facing path stays green on every PR.

## Acceptance Criteria
- [ ] `apps/warewolf/e2e/landing.spec.ts`:
  - Cold load → lang toggle persists across reload (localStorage).
  - CTA "Find a balanced setup" navigates to `/[lang]/setup`.
- [ ] `apps/warewolf/e2e/customize-loop.spec.ts`:
  - Open valid setup → make 3 swaps → balance scale + banner update live → Save → URL updates → reload → exact setup renders.
- [ ] `apps/warewolf/e2e/share-roundtrip.spec.ts`:
  - From landing → tap "Classic Detective var I @ 8p" on setup list → land in customize → swap seer for witch → save → reload → same setup renders.
- [ ] `apps/warewolf/e2e/invalid-url.spec.ts`:
  - Paste `/setup/customize?p=99&roles=foo,bar,baz` → app lands at p=20 (clamped, toast shown), unknowns substituted to villagers (silent), role-count-mismatch banner visible.
- [ ] `apps/warewolf/e2e/locale-toggle.spec.ts`:
  - Open `/en/setup/customize` with a setup → toggle to TH → all strings switch language → setup state unchanged.
  - Hit `/en/setup?lang=th` → server-side 301 redirects to `/th/setup` per Eng Review decision #5.
- [ ] **Clipboard fallback test** (in `customize-loop.spec.ts` or a dedicated spec):
  - Mock `navigator.clipboard.writeText` to reject.
  - Click Save → `<textarea> + execCommand('copy')` fallback path executes.
  - Toast shows "Link copied (fallback)".
  - Per Eng Review failure-mode mitigation #1.
- [ ] **Card 404 test** (component-level OR E2E):
  - Mock or remove a card art file → `<CardArt>` falls back to `<CardArtPlaceholder>`.
  - Placeholder shows role name + balance badge.
  - Per Eng Review failure-mode mitigation #2.
- [ ] All specs run in headless Chromium via `bunx playwright test`.
- [ ] `playwright.config.ts` has `workers: 1` per CLAUDE.md (workspace convention).
- [ ] Typecheck passes: `cd apps/warewolf && bunx tsc --noEmit`.
- [ ] Lint passes: `bun run lint`.
