# US-011: next-intl + locale precedence (301 redirect)

**Lane:** C. i18n
**Depends on:** US-009
**Priority:** 11

## Description
As a developer, I need next-intl wired with the `/[lang]/` route segment as the canonical locale source, with a middleware that 301-redirects `?lang=` query mismatches, so the locale never goes ambiguous.
