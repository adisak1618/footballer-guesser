# US-026: A11y verification — axe-core + manual SR pass

**Lane:** H. A11y + launch
**Depends on:** US-019, US-020, US-021, US-022
**Priority:** 26

## Description
As a maintainer, I need automated axe-core integration on every page plus a documented manual screen-reader and keyboard pass, so the app meets the Pass 6 accessibility floor before public launch.

## Acceptance Criteria
- [ ] `@axe-core/playwright` added to `apps/warewolf/devDependencies`.
- [ ] Each of the 5 Playwright specs in US-024 includes an axe scan: `await new AxeBuilder({ page }).analyze()` with **zero `serious` or `critical` violations** per page.
- [ ] **Keyboard tab order verified**: Tab traverses top-to-bottom, left-to-right per Pass 6. Document the expected order in `apps/warewolf/A11Y.md` (new file).
- [ ] **Focus rings** are 2px blood-red @ 2px offset on every interactive element per Pass 6. Visual test (manual or storybook screenshot).
- [ ] **44px tap targets** enforced via either:
  - A Vitest CSS check (parse `globals.css` for size assertions on `.btn`, `.chip`, `.card` classes), OR
  - Manual checklist with screenshots in `A11Y.md`.
- [ ] **Manual screen reader pass** documented in `A11Y.md`:
  - VoiceOver (macOS) — tested by hand on customize page; balance scale + banner announcements verified via `aria-live="polite"`.
  - One paragraph per page describing the SR experience.
- [ ] **`prefers-reduced-motion`** verified: all transitions zero out when set. Playwright spec sets the media query + asserts no animation.
- [ ] Tests written: `apps/warewolf/e2e/a11y.spec.ts` covering the axe scans + reduced-motion check.
- [ ] Typecheck passes: `cd apps/warewolf && bunx tsc --noEmit`.
- [ ] Lint passes: `bun run lint`.

## Technical Notes
- Per Pass 6: focus rings, 44px floor, keyboard nav, ARIA landmarks, `aria-live`, `prefers-reduced-motion`, light-only V1.
- Per Pass 7 motion table: every transition has a 0ms reduced-motion variant.
- If axe finds any `serious` or `critical` issue, fix the underlying code; do not suppress in axe config.
