## Description
As a developer, I need the three "result" components that display solver/validator output: the balance scale on customize, the Playable banner below it, and the solver-error row that surfaces when `pickWolvesForBalance` throws.

### `<BalanceScale>`
- [ ] `apps/warewolf/components/BalanceScale.tsx`.
- [ ] Props: `wolfSum: number`, `villageSum: number`, `balance: number`, `hasBlocker: boolean`.
- [ ] Layout: **Wolves total on LEFT, Village total on RIGHT** (per Pass 1 — names the threat first).
- [ ] Sizes (per design doc + Eng Review reconciliation): pointer 42px circle, side sums 30px italic, balance number large.
- [ ] Pointer color:
