# US-016: `<SetupCard>` (setup-list row)

**Lane:** E. Components
**Depends on:** US-013, US-014
**Priority:** 16

## Description
As a player, I need one card per (archetype × variation) recommendation in the setup list so I can quickly compare 24 options at a glance and tap one to customize it.

## Acceptance Criteria
- [ ] `apps/warewolf/components/SetupCard.tsx`.
- [ ] Props: `setup: Setup` (from US-005), `onTap: (setup: Setup) => void`.
- [ ] Renders, per design doc lines 484–499:
  - Archetype seal + name + roman numeral (I/II/III).
  - Vibe quote (Cormorant italic) from `setup.vibe` (current language only).
  - **Balance number with prose verdict** — `BALANCED / VILLAGE TILT / WOLF TILT` per Pass 1, mirroring the customize banner.
  - Role chips for every role in `setup.roles`, with `×N` count badge for duplicates.
  - `WW : VV : NN` team count summary (wolves : village : neutrals).
  - Tap affordance (chevron or "Customize ▸" link).
- [ ] Tap fires `onTap(setup)` — parent navigates to `/setup/customize` with that setup pre-loaded.
- [ ] Tap target ≥ 44px.
- [ ] Tap visual: 200ms scale 0.97 + opacity 0.85 per Pass 3 (respects `prefers-reduced-motion`).
- [ ] Keyboard: card is a button; Enter/Space activates. Focus ring 2px blood-red.
- [ ] Tests written: `apps/warewolf/components/SetupCard.test.tsx`:
  - Renders archetype name, vibe, balance, role chips, team counts.
  - Duplicates show `×N` badge.
  - Tap fires `onTap` with the setup.
- [ ] Typecheck passes: `cd apps/warewolf && bunx tsc --noEmit`.
- [ ] Lint passes: `bun run lint`.
- [ ] Verify in browser using dev-browser skill.

## Technical Notes
- Re-roll and Open-Selected buttons are REMOVED per reconciliation. Tap = open directly.
- Card reuses `<CardArt>` (US-013) for small role chips if visuals call for it; otherwise text + balance badge is fine.
- Prose verdict logic: `BALANCED` if `|balance| ≤ 2`, `VILLAGE TILT` if positive and >2, `WOLF TILT` if negative and < -2.
