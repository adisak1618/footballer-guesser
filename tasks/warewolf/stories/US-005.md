# US-005: Solver — `apps/warewolf/lib/solver.ts`

**Lane:** A. Data
**Depends on:** US-001, US-002, US-003, US-004
**Priority:** 5

## Description
As a developer, I need the pure-function solver — the math core of the entire app — that picks wolf compositions per archetype using DFS over the per-archetype wolf pool, satisfying singleton + pack-required + max-wolf-cub constraints, and emitting the closest-to-target balance.

## Acceptance Criteria
- [ ] File created at `apps/warewolf/lib/solver.ts` (pure module, no DOM/browser APIs; isomorphic).
- [ ] Exports `communityWolfCount(n: number): number` returning the community-standard wolf count: `1@≤5, 2@6–9, 3@10–13, 4@14–20`. (Note: prototype function is misleadingly named `bookletWolfCount`; rename to `communityWolfCount`.)
- [ ] Exports `pickWolvesForBalance(archetypeId: ArchetypeId, count: number, targetSum: number): RoleId[]`:
  - Filters `WOLF_POOLS[archetypeId]` to remove `PACK_REQUIRED` roles when `count === 1`.
  - DFS over filtered pool with replacement, respecting `SINGLETON_WOLVES` (max 1 each) and `MAX_WOLF_CUB = 2`.
  - Picks the composition minimizing `|sum − targetSum|`.
  - **THROWS on empty filtered pool** per Eng Review decision #2 (replaces prototype's `return ['werewolf']` bug at `finalized.html:699`). Error message: `Solver pool exhausted for ${archetypeId} (count=${count})`.
  - Deterministic — same args always return the same composition (no PRNG).
  - Returns array of length exactly `count`.
- [ ] Exports `generateVariations(archetypeId: ArchetypeId, playerCount: number): Setup[]`:
  - `wolfCount = communityWolfCount(playerCount) + ARCHETYPES[archetypeId].wolfDelta`.
  - For each of the 3 `VILLAGE_SEEDS[archetypeId]` entries: compute filler villagers, `targetWolfSum = -(villageSum + neutralSum + fillerSum)`, then `pickWolvesForBalance`.
  - Returns 3 Setup objects with `archetypeId`, `variationIdx`, `roman` (I/II/III), `roles[]` (length === playerCount), `balance` (sum of role.balance), `vibe` (from seed).
- [ ] Exports `computeSetupList(playerCount: number, activeFilters?: Set<ArchetypeId>): Setup[]`:
  - Filters `ARCHETYPES` to those with `minPlayers ≤ playerCount ≤ maxPlayers`.
  - Applies `activeFilters` if non-empty (otherwise show all valid).
  - Calls `generateVariations` per surviving archetype, **catches throws** and substitutes a marker the UI renders as `<SolverErrorRow>` (US-014).
  - Returns flattened list sorted by `|balance|` ASCENDING (most balanced first).
- [ ] Tests written: `apps/warewolf/lib/solver.test.ts` with these specs:
  - `communityWolfCount` table: `n=5→1, n=6→2, n=9→2, n=10→3, n=13→3, n=14→4, n=20→4` plus boundary `n=4→1`.
  - `pickWolvesForBalance`: count=1 filters PACK_REQUIRED; SINGLETON max=1; wolf-cub max=2; empty pool THROWS with expected message; deterministic (same args → same result); count=0 returns `[]` safely.
  - `generateVariations`: returns 3 entries; `wolfDelta` applied (`wolf-chaos` has +1 wolf); roles length === playerCount.
  - `computeSetupList`: hides archetypes outside `[min,max]Players`; filter narrows list; sorted by `|balance|` ASC; empty result for nonsense count.
  - **Solver perf assertion: `computeSetupList(20)` completes in < 50ms** per Eng Review perf gate (10× margin over realistic 5ms).
- [ ] Typecheck passes: `cd apps/warewolf && bunx tsc --noEmit`.
- [ ] Lint passes: `bun run lint`.
