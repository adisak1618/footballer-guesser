# US-018: `useWarewolfStore` Zustand store

**Lane:** E. Components
**Depends on:** US-009
**Priority:** 18

## Description
As a developer, I need a thin Zustand store that holds transient client state (player count, chip filters, current setup, dirty flag, lang) so components avoid prop-drilling and the URL stays the canonical shareable state.

## Acceptance Criteria
- [ ] `apps/warewolf/lib/store.ts` exports `useWarewolfStore` (Zustand).
- [ ] State shape:
  ```ts
  {
    playerCount: number;       // default 8
    activeFilters: Set<ArchetypeId>;  // default empty (= show all)
    currentSetup: RoleId[];    // populated on customize page load
    dirty: boolean;            // true when currentSetup diverges from initial URL state
    lang: 'en' | 'th';         // mirrors URL segment; localStorage-persisted
  }
  ```
- [ ] Actions: `setPlayerCount`, `toggleArchetypeFilter`, `setCurrentSetup`, `markDirty`, `setLang`, `reset`.
- [ ] **`lang` persists to localStorage** (`zustand/middleware` persist plugin or manual `useEffect`). Default 'en' on first visit.
- [ ] **URL remains the canonical source of shareable state** per Eng Review decision #4 — the store is for transient UI state only. `currentSetup` is initialized from URL on mount; `dirty` flips true on user mutations; URL updates via `router.replace()` (not store).
- [ ] Total size target: ~30 LOC per Eng Review decision #4.
- [ ] Tests written: `apps/warewolf/lib/store.test.ts`:
  - Default state matches spec.
  - `toggleArchetypeFilter` adds/removes from set.
  - `setCurrentSetup` populates roles; `markDirty` flips flag.
  - `lang` persists to localStorage between hydrations.
- [ ] Typecheck passes: `cd apps/warewolf && bunx tsc --noEmit`.
- [ ] Lint passes: `bun run lint`.
