# US-021: `/[lang]/setup/customize/page.tsx` — customize loop

**Lane:** F. Routes
**Depends on:** US-007, US-014, US-017, US-018
**Priority:** 21

## Description
As a player, I need the customize page where I can see my room as a card grid, tap any card to swap or delete, add roles, watch the balance scale + Playable banner update live, and copy the share URL — matching the locked Pattern D v2 spec.

## Acceptance Criteria
- [ ] `apps/warewolf/app/[lang]/setup/customize/page.tsx` — Client Component.
- [ ] Hydration: read URL `?p`, `?roles`, `?lang` via `decodeSetup` (US-007). Show toast if `clampedP === true`. Substitute unknown role IDs silently (parser does this per Eng Review decision #3). On Zod failure, fall back to a default setup (`p=8`, all villagers) and show "Imported setup invalid" banner per design doc lines 472–477.
- [ ] **Pattern D v2 layout** (locked at design review):
  - Sticky top: `<BalanceScale>` (US-014) above `<PlayableBanner>` (US-014).
  - **Card grid** of roles in the current setup. Each role rendered via `<CardArt size="md">` with balance corner badge + `×N` count badge for duplicates. 4-column on mobile portrait.
  - **Empty slots** when `currentSetup.length < playerCount`: render dashed "Pick a role" placeholders for each missing slot per design doc lines 518–519.
  - **Add Role tile** (dashed) at end of grid → opens `<AddRoleSheet>` (US-017).
  - Tap a card → `<RoleDetailModal>` (US-017) opens with that role.
- [ ] **Desktop (≥1024px)**: 2-column layout per Pass 6. Card grid LEFT, sticky `<RoleDetailModal>` rendered as right-column panel (replaces overlay) when a role is selected.
- [ ] **Save CTA** at sticky bottom: copies `encodeSetup({playerCount, roles, lang})` to clipboard via `navigator.clipboard.writeText`. **On rejection (insecure context / private browsing), fall back** to `<textarea> + document.execCommand('copy')`. Toast on success: "Link copied · คัดลอกลิงก์แล้ว". Toast on fallback: "Link copied (fallback)".
- [ ] **Save is disabled** when `validate(setup, playerCount).ok === false`.
- [ ] Role state lives in `useWarewolfStore` (US-018); URL updates via `router.replace()` on each mutation per design doc lines 244–245.
- [ ] `aria-live="polite"` on the balance scale + banner so screen readers announce updates.
- [ ] **Escape** closes any open modal/sheet per Pass 6.
- [ ] Tests: covered by E2E `customize-loop.spec.ts` + `invalid-url.spec.ts` + clipboard fallback test in US-024.
- [ ] Typecheck passes: `cd apps/warewolf && bunx tsc --noEmit`.
- [ ] Lint passes: `bun run lint`.
- [ ] Verify in browser using dev-browser skill (mobile + desktop).

## Technical Notes
- Per Eng Review failure-mode mitigation #1: clipboard MUST have textarea fallback. Toast must not lie.
- Per Eng Review decision #3: unknown IDs from URL are silently substituted with villager BEFORE the validator runs.
- Approved layout: `~/.gstack/projects/board-game/designs/warewolf-customize-20260512/wireframe-D-v2.html`.
- Memoize `validate(setup, playerCount)` to avoid recomputing on unrelated re-renders.
